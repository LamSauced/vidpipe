      Prompts Exactly what is sent. Clear a system box to send no system message; clear a user box to send just the data — the idea, script or segment — with no wrapper text.

      System prompts and user messages are yours to edit — nothing is injected behind them. Placeholders, replaced before sending — any case, braced or bare:
      number of segments  {segment_count}  {x}  SEGMENT_AMOUNT
      seconds per segment  {segment_seconds}  {duration}
      total length  {total_seconds}
      Braces are required for short names: {x} is replaced, a bare x is not — it would mangle ordinary prose.
